# Workspace 1C 1.0.0.34

Дата выпуска: **2026-10-21**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **«Вкладки списка баз»: при переключении Все/Избранное/Недавние с
  непересекающимся составом коллекции заменяются одним событием вместо сотен
  поштучных (issue #21, Windows и Linux; эксперимент A)** — при сохранении менее
  четверти состава `ReplaceItemWise` выполняет Reset одним событием: переход
  «Все»(600) → «Недавние»(10) больше не порождает ~590 поштучных `Remove`/`Insert`,
  каждое из которых WPF обрабатывал через `ItemContainerGenerator` (источник роста
  кучи ~10–20 МБ за переключение на Windows). Узлы дерева групп корректно
  отписываются от своих коллекций `Infobases`/`Children` при удалении
  (`GroupNodeViewModel.Detach`) — пересборки дерева не оставляют «висящих»
  обработчиков. Лог `CM_TREESWITCH` дополнен полем `resetMode` (reset|itemwise) —
  замеры 1.0.0.34 сопоставляются с 1.0.0.33 по режиму замены коллекции.
- **«Переход к строке»: выделение и прокрутка к целевой базе снова работают
  (issue #31, Windows и Linux)** — «Найти в списке» (Ctrl+T) и переход к закладке
  (Ctrl+цифра) раскрывают нужную папку, выделяют строку базы в её группе во «Все
  базы» и прокручивают список к ней, а не оставляют выделение на копии в
  «Закреплённых» (узел «Закреплённые» идёт первым в дереве, и прежний путь
  восстановления «перескакивал» на первую копию): цепочка групп-предков
  принудительно раскрывается со снятием ключей свёрнутых до и после пересборки;
  окно выполняет единственное явное выделение+прокрутку по запросу перехода,
  независимо от «чистой смены вкладки» (регрессия 1.0.0.26–1.0.0.31; фикс 1.0.0.32
  не сработал из-за дублирующих промежуточных восстановлений). Добавлены тесты
  `GoToRowTests` — переход выбирает домашнюю строку базы, а не первую копию
  в «Закреплённых».

Это диагностический релиз: после 30 переключений вкладок на Windows просим автора
issue #21 прислать лог `CM_TREESWITCH` (heapAfterGcMb, gc0/gc1/gc2, resetMode) —
по замерам фиксируется окончательный порог режима Reset.
