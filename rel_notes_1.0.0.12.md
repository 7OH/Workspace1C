# Workspace 1C 1.0.0.12

Дата выпуска: **2026-10-18**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Управление службами (issue #11)

- **Группы служб**: окно группы (Описание, «Управляемый список» / «Все службы», перенос
  стрелками, порядок членов), иконка-индикатор и статус группы (зелёный — все запущены,
  жёлтый — частично, серый — не запущены); команды группы выполняются по всем службам
  группы в порядке списка; новая группа добавляется в начало списка, группы перемещаются
  вверх/вниз.
- **Меню служб в трее**: подменю «Службы» над «Синхронизацией с ibases» — «Настроить…»,
  подменю для каждой службы и группы (у группы — сначала команды действий, затем её
  службы), «Все сервисы» (Windows и Linux). На Windows Ctrl+правый клик по иконке трея
  открывает меню служб.
- **`services.json`**: объектный формат (службы, группы, порядок); старый формат (массив
  строк) при чтении мигрируется автоматически.
- Расширено покрытие тестами: хранилище и миграция формата, окно группы, статусы групп,
  построение меню трея, порядок и команды групп.

Подробности — в [CHANGELOG.md](CHANGELOG.md).
