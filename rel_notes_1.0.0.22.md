# Workspace 1C 1.0.0.22

Дата выпуска: **2026-10-19**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **«Серверы 1С»: на папках-группах в меню «СЛУЖБЫ» снова виден цветной кружок статуса
  (issue #3, Windows и Linux)** — микс-иконка «папка 📦 + кружок статуса справа-снизу»
  (зелёный — все запущены, жёлтый — частично, серый — не запущены), которая у групп есть в
  меню служб трея и в контекстном меню служб главного окна, отсутствовала в WPF- и
  Avalonia-версиях меню «СЛУЖБЫ» окна «Серверы 1С» — замечание 7OH от 19.10 («отсутствует
  доп иконка кружочек на папках»). Исправление: `MenuGroupIcon` (папка + кружок по
  `ServiceMenuItem.StatusColorHex`) добавлен в `ToWpfServiceMenuItem`
  (`ServerMonitorWindow.xaml.cs`) и `ToAvaloniaMenuItem` (`ServerMonitorWindow.Avalonia.cs`).
  Цвет кружка группы по-прежнему даёт чистый `ServiceTrayMenuBuilder` (`GroupStatusHex`);
  при пустом кэше статусов и неизвестных службах — обычная папка без кружка (меню не ломается).
- **«Серверы 1С»: исправлена ошибка «Вызывающим потоком должен быть STA» при добавлении базы
  (issue #3, Windows)** — `CreateInfobaseAsync` после `await ... .ConfigureAwait(false)`
  создавал WPF-окно предупреждения `MaterialMessageWindow` из потока пула (стек 7OH от 19.10:
  «Попытка просто добавить базу в список — выдаёт ошибку интерфейса»). Исправление: все
  вызовы `_dialogs.ShowWarning` в `ServerMonitorViewModel` (создание/изменение/удаление базы,
  завершение сеанса, разрыв соединения, сохранение свойств кластера, разбор чисел полей
  кластера) перенесены в UI-поток через существующий маршалер `_dispatchToUi` (helper
  `ShowWarningOnUi`); на Linux/Avalonia поведение не изменилось (Avalonia не требует STA).
