Workspace 1C — описание для публикации на Infostart

Текст подготовлен по материалам проекта (README, CHANGELOG, ARCHITECTURE, rel_notes) для версии 1.0.0.35 от 21.10.2026. Перед публикацией: загрузите скриншоты в галерею (главное окно docs/img/main-window.png, тёмная тема, «Центр обслуживания», «Серверы 1С», окно настроек «Темы») и приложите в раздел «Файлы» сборки для Windows и Linux.

Название публикации

Workspace 1C — бесплатный кроссплатформенный менеджер информационных баз 1С (Windows и Linux)

Краткое описание (анонс)

Бесплатная замена стандартного списка баз 1С с открытым исходным кодом. Запуск баз в нужной версии и разрядности, группы, теги, палитра команд Ctrl+K, резервное копирование по расписанию, обновление конфигураций и платформы, монитор серверов 1С, очистка кэша, синхронизация с ibases.v8i. Один исполняемый файл, без установки .NET. Windows 10/11 и Linux (Ubuntu, Debian, Astra, ALT).

Ключевые слова

список баз 1С, стартер 1С, ibases.v8i, менеджер баз, очистка кэша 1С, резервное копирование 1С, rac, кластер 1С, хранилище конфигурации, Linux, Astra Linux, Avalonia, WPF, .NET, open source

О программе

Workspace 1C — десктопное приложение для разработчиков, администраторов и пользователей 1С:Предприятие 8.3, которое заменяет штатное окно выбора информационных баз. Помимо удобного списка баз, в программе собраны инструменты, ради которых обычно держат открытыми конфигуратор, консоль кластера, проводник и пару самописных скриптов.

Workspace 1C — новое название программы «Управление конфигурациями 1С». Все возможности сохранены, нумерация версий начата заново с 1.0.0.0. При первом запуске список баз, группы, настройки, профили и задания автоматически переносятся из каталога прежней версии; старый каталог не удаляется.

Одна кодовая база на .NET 10 собирается под две ОС: WPF на Windows и Avalonia 11 на Linux. Программа распространяется одним исполняемым файлом: устанавливать .NET не нужно.

Кому пригодится

  • Разработчикам 1С — десятки баз разных версий платформы, быстрый запуск конфигуратора, работа с хранилищем, сравнение конфигураций, обозреватель метаданных.
  • Администраторам — монитор серверов 1С, сеансы и блокировки, службы, резервные копии и обновления по расписанию, отчёты в Telegram и на почту.
  • Пользователям — понятный список баз с поиском и избранным, упрощённый режим интерфейса без лишних команд.
  • Тем, кто переходит на Linux — одна и та же программа и одни и те же данные на Windows и на Linux.

Основные возможности

Запуск информационных баз

  • Запуск в режимах «1С:Предприятие» и «Конфигуратор», выбор тонкого, толстого или веб-клиента.
  • Выбор версии платформы, в том числе неполной (8.3, 8.3.27 — берётся новейшая установленная сборка), и разрядности: приоритет 32/64, только 32/64.
  • Отдельные учётные данные для запуска, конфигуратора и хранилища.
  • Скрипты «до» и «после» запуска и внешняя обработка (.epf/.erf), открываемая при старте базы.
  • «Перейти по ссылке» — запуск по e1c://…, сервер\база, http(s)://….
  • Запуск из командной строки без окна: --run "Имя базы", --designer, --list, --json — для ярлыков, скриптов и планировщика ОС.

Список баз

  • Вкладки «Все / Избранное / Недавние / Запущенные», вложенные группы с цветами и иконками.
  • Поиск по названию и тегам, облако тегов, мультифильтр.
  • Палитра команд Ctrl+K — найти базу или команду интерфейса по названию; Enter запускает Предприятие, Shift+Enter — Конфигуратор.
  • Закладки Alt+1…Alt+9 для избранных баз, закрепление важных баз сверху.
  • Зелёная точка у базы, которая уже запущена, — чтобы не открыть её второй раз.
  • Проверка доступности всех баз в фоне: файловые, клиент-серверные (через COM-коннектор), веб.
  • Мультивыделение и пакетные операции, массовая замена сервера и пути в строке подключения.
  • Произвольные поля базы, пользовательские действия в контекстном меню с подстановкой параметров базы.
  • Приватные базы, скрытые до разблокировки профиля.
  • Drag & drop каталога базы или файла 1Cv8.1CD из проводника.

Создание и обслуживание баз

  • Создание пустой базы или из шаблона .cf/.dt, файловой и клиент-серверной.
  • Дублирование базы (в том числе клиент-серверной) для экспериментов на копии.
  • Выгрузка .dt/.cf, список выгрузок и восстановление базы из них.
  • Очистка кэша 1С по базам с показом размеров и «остатков» от удалённых баз.
  • Блокировка сеансов файловой базы по расписанию и проверка целостности (chdbfl) без открытия Предприятия.
  • Поиск потерянных баз на дисках и добавление их в список.
  • Инспектор процессов 1С — какой процесс держит какую базу.
  • Центр обслуживания — доступность, копии, размер и свободное место по всем базам на одном экране, фильтр «Только проблемы».
  • HTML-отчёт и экспорт списка в CSV, статистика использования баз.

Резервное копирование и задания по расписанию

  • Сценарии резервирования: выгрузка DT/CF, упаковка в ZIP/RAR, копирование в несколько каталогов, шаблон имени файла.
  • Задания по расписанию: копия, обновление конфигурации из .cf, связка «копия → обновление», обновление самой программы.
  • Пропущенные во время простоя задания выполняются после включения компьютера.
  • Уведомления о результатах в Telegram и по email.

Обновления 1С

  • Проверка обновлений конфигурации (F9) с построением цепочки версий, если прямого обновления нет.
  • Актуальные релизы (Alt+F9) — пакетная проверка и загрузка отслеживаемых типовых конфигураций.
  • Обновление платформы 1С (Ctrl+F9) — установка новой версии на Windows, готовая команда установки на Linux, удаление старых версий.

Серверы, службы и хранилище

  • Серверы 1С (Ctrl+Alt+S) — встроенный монитор кластеров, рабочих процессов и сеансов: завершение сеансов, снятие блокировок, создание и удаление баз на сервере. Поддерживается rac, включая платформу 8.5.
  • Импорт баз из кластера 1С в свой список.
  • Диагностика сети: доступность сервера и его портов.
  • Управление службами (Ctrl+Shift+S) — запуск и остановка служб системы, группировка, быстрое меню служб из трея.
  • Хранилище конфигурации — версии, сравнение, захват объектов без конфигуратора; пакетное обновление баз из хранилищ.
  • Обозреватель метаданных и сравнение конфигураций (база ↔︎ .cf или два файла).

Перенос и синхронизация списков

  • Синхронизация с ibases.v8i: загрузка, выгрузка или двусторонняя, при старте, по интервалу или расписанию.
  • Экспорт и импорт в произвольный файл *.v8i и в JSON — переезд на другой компьютер без потерь.
  • Импорт из StartManager.

Интерфейс и настройки

  • 8 встроенных тем: Светлая, Тёмная, Синяя, Зелёная, Material Design, macOS, Windows XP, Glass; собственные цветовые схемы с экспортом в JSON.
  • Компактный режим, настройка шрифтов, колонок и заголовка окна (с переменными вроде %computer_name%).
  • Свои горячие клавиши для всех основных команд.
  • Режимы функциональности «Пользователь / Специалист / Разработчик» — лишнее можно скрыть.
  • Несколько профилей пользователей с паролем (PBKDF2-SHA256), блокировка интерфейса паролем.
  • Системный трей с недавними базами, автозапуск вместе с ОС, портативный режим.
  • Русский и английский интерфейс, подключение других языков без пересборки.
  • Автообновление из GitHub Releases.

Технологии

Технология Назначение
.NET 10 Платформа (net10.0-windows / net10.0)
WPF Интерфейс на Windows
Avalonia 11 Интерфейс на Linux
MVVM + Microsoft.Extensions.DependencyInjection Архитектура
System.Text.Json Хранение данных в JSON

Данные хранятся в %APPDATA%\Workspace1C (Linux — ~/.config/Workspace1C) в открытом JSON-формате.

Требования

Windows: Windows 10/11 x64, установленная платформа 1С:Предприятие 8.3.

Linux: x64 (Ubuntu LTS, Debian, Astra Linux, ALT Linux), платформа 1С:Предприятие 8.3 для Linux, GTK3, glib2, xdg-utils. Для значка в трее на GNOME может понадобиться расширение AppIndicator. Проверка доступности клиент-серверных баз через COM-коннектор на Linux недоступна.

Установка

  1. Скачайте файл из раздела «Файлы» публикации или со страницы Releases.
  2. Windows: запустите Workspace1C.exe. Linux: chmod +x Workspace1C-linux-x64 && ./Workspace1C-linux-x64.
  3. При первом запуске программа предложит импортировать базы из ibases.v8i; данные «Управления конфигурациями 1С», если оно стояло, перенесутся автоматически.

Дальше программа сама проверяет наличие новых версий и предлагает обновиться.
