# Workspace 1C 1.0.0.3

## Добавлено

- **Произвольные поля базы** (issue #6, Windows и Linux): на вкладке «Идентификатор» окна
  свойств базы появилась таблица «Произвольные поля» с колонками «№» (порядковый номер, не
  редактируется) и «Значение поля» (высота по умолчанию 4–5 строк). Кнопки «Добавить /
  Изменить / Удалить»; добавление и правка значения выполняются в отдельном модальном окне
  (закрывается по ESC, фокус сразу в поле «Значение»). Рядом с кнопками правки — кнопка
  «Сценарии…», открывающая список сценариев запуска скриптов. Значения сохраняются в
  `infobases.json` (поле `AdditionalFields`), переносятся экспортом/импортом JSON и
  дублированием базы.
- **Подстановка `%Additional_N%` в сценариях** (issue #6, Windows и Linux): при формировании
  строки запуска сценария (и пользовательских действий) токен `%Additional_N%`/`{Additional_N}`
  заменяется значением N-й строки таблицы «Произвольные поля» выбранной базы (например,
  `%Additional_1%` — первая строка). Номер может быть любым; если строки с таким номером нет —
  токен остаётся в строке как есть. В форме правки сценария список «Подстановки» дополнен
  примером `%Additional_1%`.

## Изменено

- **Группа «Новинки программы» в меню «Утилиты»** (issue #4, Windows и Linux): видимость
  папки в рабочем меню теперь определяется наличием пунктов, а не галочкой видимости в
  редакторе структуры. Если внутри папки пунктов нет — она не показывается; как только
  появляются новые пункты, попадающие в неё, папка становится видимой безусловно.
