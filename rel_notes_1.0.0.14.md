# Workspace 1C 1.0.0.14

Дата выпуска: **2026-10-18**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Управление службами (issue #11)

- **Иерархический список**: службы показываются внутри папок-групп, как базы внутри
  групп в основном окне. Элемент (служба) может находиться ровно в одном месте — в
  одной группе или в корне; исключённые при правке группы службы возвращаются в
  корневой список, «Все сервисы» охватывают корневые службы и членов групп.
- При правке группы в «доступные» попадают только службы, которые не состоят в
  других группах И не состоят в этой же группе.
- Перед кнопками «Выше/Ниже» добавлены «Свернуть все»/«Развернуть все» (иконки,
  с разделителем после них) — как в основном окне.
- Рядом с кнопкой правки добавлена кнопка «Перенести в группу»: диалог с выбором
  группы (или «Без группы» — корневой список), в контекстном меню — пункт
  «Перенести в группу…».
- **Ctrl+клик в трее** теперь открывает меню служб мгновенно: статусы читаются из
  вновь введённого кэша (`ServiceStatusCache`) и обновляются в фоне — задержка
  около секунды устранена (Windows и Linux).
- Контекстное меню строки и подменю «Все сервисы» по-прежнему в едином виде
  контекстного меню основного окна (иконки, подписи, доступность по состоянию);
  на Linux пункты дополнены цветными глифами для паритета.

## Серверы 1С (issue #3)

- **Свойства информационной базы**: первая вкладка — «Настройки» (там чаще всего
  вносят исправления); вкладка «Основная» стала компактнее — чекбокс «Разрешить
  выдачу лицензий» виден на типовых разрешениях; контент вкладок прокручивается.
  Тип СУБД файловой базы в диалоге больше не подменяется на MSSQLServer.
- **Удаление базы**: вариант «Удалить с удалением на сервере СУБД» теперь доступен
  только для заведомо клиент-серверных СУБД (белый список); для файловой базы
  кластера остаётся только «Просто удалить из кластера» (исправлена логика
  определения файловых баз — комментарий 7OH 18.10).
- Меню кнопки «СЛУЖБЫ» приведено к виду контекстного меню основного окна:
  кружки статусов, папки групп, цветные глифы команд (Windows и Linux).
