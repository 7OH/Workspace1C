# Workspace 1C 1.0.0.21

Дата выпуска: **2026-10-19**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **«Серверы 1С»: кнопка максимизации убрана у окна создания базы и окна удаления базы
  (issue #3, Windows и Linux)** — в v1.0.0.19 подавление максимизации
  (`SuppressMaximizeButton`/`CanResize=false`) было применено к окну создания **локальной**
  базы (`CreateInfobaseWindow`), а не к окну создания базы **кластера**
  (`RacInfobaseCreateWindow`), и не было применено к окну удаления базы
  (`RacInfobaseDropWindow`) — замечание 7OH от 19.10. Исправление: `SuppressMaximizeButton`
  добавлен в `RacInfobaseCreateWindow` и `RacInfobaseDropWindow` (WPF), в Avalonia-версиях
  `CanResize=false` (кнопка разворота в системном заголовке управляется через `CanResize`).
  Ресайз у окна создания базы сохранён, максимизация подавлена (Win+Up, двойной клик по
  шапке); большие окна (монитор серверов, главное окно) максимизацию сохранили.
- **«Серверы 1С»: вариант «Удалить с удалением на сервере СУБД» показывается для ВСЕХ баз
  списка кластера (issue #3, Windows и Linux)** — в v1.0.0.19 второй вариант удаления
  зависел от распознанного типа СУБД (белый список `MSSQLServer/PostgreSQL/IBMDB2/
  OracleDatabase`), и на версиях rac с нестандартным значением колонки `dbms` вариант
  по-прежнему не показывался — замечание 7OH от 19.10 («в списке баз в этом окне НЕ МОЖЕТ
  быть НЕ клиент-серверных баз»). Исправление: в кластере 1С бывают только клиент-серверные
  базы (инвариант кластера), поэтому `CanDropDatabaseOnServer` теперь возвращает `true` для
  любой базы списка кластера независимо от распознанного `dbms`; белый список СУБД остался
  только диагностической подписью в диалоге удаления и больше не блокирует вариант.
  Диагностическая подпись «Тип СУБД: …; Сервер СУБД: …» в диалоге удаления сохранена.
