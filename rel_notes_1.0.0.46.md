# Workspace 1C 1.0.0.46

Дата выпуска: **2026-10-22**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **Устранён рост памяти при переключении вкладок «Все / Избранное / Недавние» на Windows
  (1.0.0.46, issue #21)** — при чистом переключении вкладок heapAfterGcMb рос с каждой
  сменой (42 → 269 МБ за ~50 переключений, ~5 МБ/смена): сброс Recycling-пула теперь
  выполняется и для корневого дерева в плоском режиме (flushPanels>0), старые контейнеры
  строк освобождаются. В плоском режиме (группы не реализованы, вкладка — одиночный
  плоский узел) `FlushTreeRecycledContainers` не находила дочерних контейнеров, список
  ограничивался одним MainTree, и ранний return (`containers.Count <= 1`) оставлял очередь
  Recycler'а корневого дерева неразобранной — рециклированные контейнеры строк
  удерживались пулом `ItemContainerGenerator` вместе с данными (в логах CM_TREESWITCH:
  `flushPanels=0` при `rowsRealized`/`rowsCleared` 16–21 за смену). Ранний return убран:
  переключение `VirtualizationMode.Standard` и обратно выполняется всегда, хотя бы для
  самого MainTree. Планирование сброса переведено с `ApplicationIdle` на `Background`
  (при быстром переключении вкладок `ApplicationIdle` мог не наступить до следующей
  смены); подписки строк (`OnInfobaseRowGrid_Loaded`/`Unloaded`) проверены на удержание
  контейнеров — утечек обработчиков не выявлено.
