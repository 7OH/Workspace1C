# Workspace 1C 1.0.0.9

Дата выпуска: **2026-10-17**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Изменено

- **Уведомление об успешном обновлении приложения** (issue #10, Windows и Linux): задание
  по расписанию «Обновить приложение» обновлялось «молча» — процесс перезапускался раньше,
  чем уведомление о завершении доходило до Telegram. Теперь перед перезапуском пишется
  маркер `pending_update.json`, и новая версия при первом старте отправляет уведомление
  «Приложение обновлено до версии X» по включённым каналам (Telegram/email и др.)
  с учётом фильтра «Уведомлять о новых версиях». Ложных уведомлений нет: если помощник
  не смог заменить исполняемый файл (версии не совпали), маркер просто очищается.
- **Окно «Серверы 1С» (issue #3, замечания 7OH от 2026-10-17)**:
  - индикация сортировки колонок ▲/▼ теперь видна на обеих платформах;
  - окно стало немодальным; повторный запуск команды активирует уже открытое окно;
    максимизированное состояние запоминается и восстанавливается;
  - кнопки «Добавить/Изменить/Удалить» справочника перенесены над список;
  - у кнопки «Удалить» — красный текст/иконка;
  - заголовки вкладок показывают количество строк («Сеансы (12)»), порядок вкладок —
    Сеансы, Соединения, Блокировки, Рабочие процессы, Информация о кластере;
  - «Информация о кластере» — человекочитаемые значения («1 ч 30 мин», «512 МБ»,
    «Да/Нет») и группировка по секциям;
  - список баз — отдельный список слева от вкладок; клик по строке включает фильтр;
    надпись фильтра и кнопка «Сбросить» видны всегда, при сбросе — «Без фильтра»;
  - добавлена кнопка **«Изменить»** для базы (rac `infobase update`, полный диалог
    с предзаполненными полями);
  - три кнопки управления базами ужаты в одну строку иконок (у удаления — красная);
  - исправлена вечно неактивная кнопка «Удалить базу».

Подробности — в [CHANGELOG.md](CHANGELOG.md).
