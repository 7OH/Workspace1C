# Workspace 1C 1.0.0.10

Дата выпуска: **2026-10-17**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Добавлено

- **Новое окно «Управление службами»** (issue #11, Windows и Linux): пункт меню «Утилиты»
  сразу под «Серверы 1С», горячая клавиша **Ctrl+Shift+S** (настраивается в
  «Настройки → Клавиши»); окно немодальное, повторный вызов активирует уже открытое.
- **Список «Службы»**: кружок статуса (зелёный — запущена), отображаемое имя и
  локализованный текст статуса; подсказка при пустом списке. Состав служб хранится
  в `services.json` каталога данных профиля.
- **Команды управления**: «Обновить», «Запустить», «Остановить», «Пауза», «Восстановить»,
  «Перезапустить» (кнопки над списком) и подменю «Все сервисы»; контекстное меню строки —
  те же команды. Доступность кнопок зависит от состояния службы (не все поддерживают
  паузу/восстановление и т. п.); статусы перечитываются после команд и по «Обновить».
- **«Настроить»** — чеклист всех служб системы с галочками уже выбранных, поиском,
  кнопками «Выбрать все / Сбросить» и сводкой «Выбрано: N из M»; «ОК» сохраняет выбор
  в `services.json`.
- **«Системный диалог»** (Windows) — открывает `services.msc`; на Linux кнопка скрыта.
- **Windows**: управление через `System.ServiceProcess.ServiceController`.
- **Linux**: управление через `systemctl` (systemd); при отсутствии systemd действия
  недоступны, пауза/восстановление не поддерживаются, системного диалога нет.

> Группы служб и управление из системного трея запланированы на следующую итерацию
> (по замечанию 7OH).
