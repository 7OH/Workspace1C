# Workspace 1C 1.0.0.26

Дата выпуска: **2026-10-20**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **«Блокировка базы»: диалог увеличен — поле «Код разрешения» с описанием помещается без
  прокрутки (issue #20, Windows и Linux)** — высота окна увеличена (600 → 680), поле сообщения
  слегка ужато (90 → 80), отступ описания уплотнён; на малых экранах высота ограничивается
  рабочей областью (WPF — `SystemParameters.WorkArea`, Avalonia — `Screens`), чтобы кнопки не
  обрезались.
- **«Вкладки списка баз»: ускорено переключение «Все / Избранное / Недавние» (issue #21,
  Windows и Linux)** — отфильтрованные списки «Избранное»/«Недавние» кэшируются и
  пересчитываются только при изменении данных; коллекции обновляются массово (одно событие
  Reset вместо тысяч `CollectionChanged`), дерево не пересоздаётся при переключении вкладок.
- **«Загрузки»: предотвращено пересечение фоновой и ручной закачки одного файла (issue #22,
  Windows и Linux)** — введён единый реестр загрузок по целевому файлу
  (`BackgroundDownloadManager.TargetPath`); self-update регистрируется в общем реестре; перед
  ручной закачкой проверяется, не идёт ли уже загрузка того же файла, — при повторном запуске
  показывается предупреждение.

## Примечания

- Issues #20, #21 и #22 остаются открытыми до подтверждения пользователем (автозакрытие issues
  по сообщению коммита отключено).
