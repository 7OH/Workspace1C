# Workspace 1C 1.0.0.19

Дата выпуска: **2026-10-19**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **«Серверы 1С»: вариант «Удалить с удалением на сервере СУБД» снова предлагается для
  клиент-серверных баз (issue #3, Windows и Linux)** — в табличном формате вывода `rac`
  колонка `dbms` приходила в кавычках и не проходила сравнение с белым списком СУБД, поэтому
  второй вариант удаления не показывался. Исправление: `Unquote` применяется к строковым
  колонкам табличного summary (`descr`, `dbms`, `db-server`, `db-name`, `db-user`) — по
  образцу блочного формата. В диалоге удаления базы рядом с именем показывается распознанный
  тип СУБД и сервер СУБД (диагностика). Добавлены фикстуры реального вывода rac и тесты.
- **«Серверы 1С»: меню «СЛУЖБЫ» приведено к виду меню служб трея/главного окна (issue #3,
  Windows и Linux)** — стили скина `ModernContextMenu`/`ModernMenuItem` (WPF); статусы читаются
  из **единого кэша** `ServiceStatusCache` (зарегистрирован в DI как singleton) — синхронный
  опрос служб при каждом показе заменён на мгновенное чтение из кэша; имена служб/групп с `_`
  экранируются через `EscapeMenuText`. На Avalonia главное изменение — тоже кэш статусов.
- **«Серверы 1С»: окно не выходит за пределы рабочего экрана (issue #3, Windows и Linux)** —
  в `WindowSizeMath` добавлены `FitLeft` и `ClampToWorkArea`; позиция окна клампится со всех
  сторон, размер ужимается до рабочей области на малых экранах (WPF — при открытии, Avalonia —
  позиционирование относительно рабочей области экрана до показа). То же для окна свойств базы.
- **«Серверы 1С»: убрана кнопка максимизации у доп. окон (issue #3, Windows и Linux)** —
  окно правки сервера больше не ресайзится; у окон создания базы и свойств базы кнопка
  «развернуть/восстановить» убрана из шапки, а `WS_MAXIMIZEBOX` снимается WndProc-хуком
  (`SuppressMaximizeButton`) — ресайз у этих окон сохранён. Большие окна («Серверы 1С»,
  «Управление службами») по-прежнему максимизируются.
- **«Серверы 1С»: подключённый сервер подсвечивается жирным (issue #3, Windows и Linux)** —
  в модель добавлены `ConnectedServer`/`HasConnectedServer` (устанавливаются при успешном
  подключении, сбрасываются при отключении/ошибке); строка активного подключения в списке
  «Сервера управления» выделяется жирным шрифтом. Подсветка показывается только при активном
  подключении.

## Примечания

- Вариант «Удалить с удалением на сервере СУБД» предлагается для известных клиент-серверных
  СУБД (MSSQLServer, PostgreSQL, IBMDB2, OracleDatabase) — по данным вывода `rac`.
- Issue #3 остаётся открытым до подтверждения пользователем (автозакрытие issues по
  сообщению коммита отключено).
