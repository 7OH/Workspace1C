# Workspace 1C 1.0.0.28

Дата выпуска: **2026-10-20**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **«Загрузки»: один индикатор прогресса при обновлении приложения и отсутствие пересечения
  фоновой и ручной закачки одного файла (issue #22, Windows и Linux)** — устранены два
  индикатора одной загрузки при ручном запуске обновления и параллельная запись в один
  временный файл при одновременном «обновлении по заданию» и ручной проверке:
  - прогресс self-update публикуется только в единый индикатор загрузок главного окна
    (убран дублирующий индикатор статус-бара в WPF и отдельное окно прогресса в автопути
    Avalonia);
  - повторный запуск обновления не начинает вторую загрузку того же файла (single-writer):
    ручной запуск блокируется предупреждением «обновление уже скачивается», фоновый и
    задачный пропускаются, повторное применение не выполняется.
