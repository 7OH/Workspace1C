# Workspace 1C 1.0.0.47

Дата выпуска: **2026-10-22**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **README: все упоминания прежнего названия программы «ConfigurationManagement» заменены
  на «Workspace1C» (1.0.0.47, issue #42, Windows и Linux)** — в блоке «Переход с „Управление
  конфигурациями 1С“» пути каталогов данных прежней версии переформулированы без старого
  имени: при первом запуске список баз, группы, настройки, профили и задания **копируются**
  из каталога данных прежней версии программы в новый каталог `%APPDATA%\Workspace1C`
  (Linux — `~/.config/Workspace1C`); старый каталог не удаляется. Портативная установка
  продолжает работать с каталогом `Workspace1C-Data` рядом с exe. Обновлены бейдж версии
  и строка «актуальная версия» в шапке README.
