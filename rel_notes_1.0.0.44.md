# Workspace 1C 1.0.0.44

Дата выпуска: **2026-10-21**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **Суффикс «(тонкий клиент)» и оранжевая подсветка отображаются во всех списках
  платформ — в настройках и при выборе версии платформы для базы (issue #33,
  1.0.0.44, Windows и Linux)** — ранее в WPF-диалоге выбора версии подсветка и
  суффикс не срабатывали из-за приоритета локальных значений над DataTrigger'ами,
  а в настройках (вкладка «Платформы») суффикса не было вовсе. Введён единый
  форматтер `PlatformDisplayFormatter` (свойство `PlatformVersionGroup.DisplayName`),
  используемый диалогом выбора и настройками на обеих платформах; шаблоны WPF
  переведены на стилевые `Setter` (DataTrigger по `IsThinClient` теперь
  гарантированно даёт оранжевую подсветку), Avalonia — на тот же форматтер.
  Полный клиент отображается без суффикса.
- **Горячие клавиши с одним Shift (Shift+клавиша) снова работают на Windows и
  Linux: матчинг по физической клавише, независимо от раскладки и верхнего
  регистра (issue #32, 1.0.0.43)** — настраиваемые хоткеи действий перестали
  полагаться на платформенный KeyBinding/KeyGesture, для которого сочетание
  «Shift+клавиша» на части систем не срабатывает; добавлен чистый матчер
  `HotkeyMatcher` по имени физической клавиши и набору модификаторов.
- **Импорт из кластера 1С: устранена остаточная ошибка после «Подключиться»
  (первая попытка загрузки при непрогретом формате rac повторяется без показа
  ошибки; автовыбор единственного кластера работает в обоих входах окна)
  (issue #25, 1.0.0.42, Windows и Linux)** — добавлена диагностика `CM_CLUSTERIMPORT`.
- **Переключение вкладок Все/Избранное/Недавние: устранён устойчивый рост памяти
  на Windows — старые узлы/строки больше не удерживаются, heapAfterGcMb стабилен
  (issue #21, 1.0.0.41)** — после чистой смены вкладки рекурсивно освобождаются
  Recycling-панели всего дерева; добавлен счётчик `Detach` (detachCount) для
  контроля отписок узлов.
- **Удалено создание лишнего файла rac_joblist_formats.json: кэш рабочих форматов
  передачи кластера rac переведён в память; существующий файл удаляется при первом
  старте (issue #39, 1.0.0.40, Windows и Linux)**.
- **Исправлено сохранение горячей клавиши «Окно обновления платформы»
  (Настройки → Клавиши): назначенное сочетание теперь сохраняется, отображается
  и применяется (issue #38, 1.0.0.39, Windows и Linux)** — на Windows поле ввода
  при открытии настроек заполняется текущим значением, сочетание перерегистрируется
  сразу после «ОК», а не только после перезапуска.
- **«Управление службами»: колонка «Временно отключить» для служб и групп;
  временно отключённые службы/папки не попадают в подменю управления службами
  (трей, контекстное меню, «Серверы 1С») (issue #37, 1.0.0.38, Windows и Linux)** —
  галочка сохраняется в `services.json`, пункт «Настроить…» остаётся доступным
  всегда.
- **Окно свойств базы показывает имя редактируемой базы в заголовке и обновляет
  его при правке поля «Наименование» (issue #36, 1.0.0.37, Windows и Linux)** —
  заголовок «Настройка информационной базы: Имя» следует за текстом поля в этом
  же диалоге; при отмене изменения не сохраняются.

  не работало из-за бага приоритета свойств WPF; в 1.0.0.44 фикс переведён на
  единый форматтер и покрывает все списки платформ на обеих платформах.
