# Workspace 1C 1.0.0.36

Дата выпуска: **2026-10-21**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **«Правка свойств базы»: строка обновляется сразу даже при активном
  отборе/поиске (issue #35, Windows и Linux)** — при прямом переносе полей
  теперь поднимается уведомление обо всех свойствах (`Infobase.NotifyAllPropertiesChanged`,
  единый помощник `InfobaseEditor.ApplyEdits` в обоих путях редактирования);
  в плоском режиме (тег/поиск/«Избранное»/без группировки) переиспользуемый
  узел больше не «замораживает» данные строк — изменения видны сразу, без
  сброса отбора.
- **«Переход к строке»: ведёт на домашнюю строку во «Все базы», а не на копию
  в «Закреплённых» (issue #31, Windows и Linux)** — найден и устранён корень:
  контейнер узла-группы искался по данным базы и совпадал с первым групповым
  заголовком — «Закреплённые». Теперь поиск контейнера идёт строго по ссылке
  узла, выполняется проверка поддерева домашнего узла и планирование
  достижимости (`RevealPlanner`); добавлена диагностика `CM_REVEAL`.
  «Найти в списке» (Ctrl+T) и переход к закладке (Ctrl+цифра) всегда
  выделяют домашнюю строку базы во «Все базы».
- **«Импорт из кластера 1С»: при единственном кластере он выбирается
  автоматически и список баз показывается сразу (issue #25, Windows и Linux)** —
  и при ручном запуске окна, и при входе из «Серверы 1С» WPF-окно
  пересчитывает кнопки/статус по `SelectedClusterId`; тесты детерминированно
  дожидаются завершения загрузки (тест-seam `LastLoadBasesTask`).
- **«Переключение вкладок»: диагностика v2 и эксперимент B по накоплению
  памяти на Windows (issue #21)** — лог `CM_TREESWITCH` дополнен `allocMb`
  и счётчиками реализованных/отсоединённых строк; добавлен флаг
  `CM_TREESWITCH_FLUSH` (эксперимент: сброс Recycling-пула
  `ItemContainerGenerator` после смены вкладки). Выпуск диагностический:
  по замерам автора после 30 переключений фиксируется окончательный режим.

## Изменено

- **Новые иконки приложения** — `app.ico`/`tray.ico` во всех размерах;
  обновлены превью для Linux (`app_icon_preview`/`tray_icon_preview`)
  и иконка AppImage/.desktop (`package/linux/app.png`). Палитры SVG —
  дизайн-артефакты, в сборку не входят.
