# Workspace 1C 1.0.0.25

Дата выпуска: **2026-10-20**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **«Блокировка базы»: высоты верхних полей диалога выровнены, диалог увеличен
  (issue #20, Windows и Linux)** — поля «Время начала» и «Длительность» были выше остальных
  (DatePicker по умолчанию выше TextBox/ComboBox); задана единая высота полей (WPF —
  `Height="36"`, Avalonia — явная высота 36). Высота окна увеличена (520 → 600), чтобы поле
  «Код разрешения» с описанием помещалось без прокрутки.
- **«Серверы 1С»: кнопки «Вверх»/«Вниз» — той же ширины, что и соседние кнопки-иконки
  (issue #3, Windows и Linux)** — глифы ↑/↓ уже соседних (＋/✎/🗑), поэтому кнопки получались
  уже; задана общая минимальная ширина кнопок-иконок (`MinWidth=40` в стиле `IconOnlyButton`
  WPF и в `BuildIconButton` Avalonia).
- **«Серверы 1С»: порт по умолчанию 1545 для нового сервера (issue #3, Windows и Linux)** —
  при добавлении сервера поле «Порт» заполнялось портом агента ragent (1540); теперь для
  новой записи справочника по умолчанию подставляется 1545 (порт сервера администрирования
  RAS). Добавлена константа `ManagementServer.DefaultPort = 1545`; фолбэк невалидного порта
  в `ServerListStore` приведён к тому же дефолту; обновлена подсказка поля «Порт» (ru/en).
  Добавлен юнит-тест `NewServer_DefaultPort_Is1545`.

## Примечания

- Issues #3 и #20 остаются открытыми до подтверждения пользователем (автозакрытие issues по
  сообщению коммита отключено).
