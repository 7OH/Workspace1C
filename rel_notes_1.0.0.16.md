# Workspace 1C 1.0.0.16

Дата выпуска: **2026-10-19**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **Окно «Очистка истории запусков»: кнопка «Очистить историю» при одной отмеченной базе
  (issue #17, Windows)** — кнопка активируется сразу при отметке флажка хотя бы одной базы
  (раньше — только при выборе всех через «Выбрать все»). Исправление: подписка на
  `PropertyChanged` строк `ClearHistoryRowViewModel` в WPF-версии окна; Avalonia-версия уже
  работала корректно. Добавлены тесты `ClearHistoryRowViewModelTests`.
- **Настройки → «Клавиши»: надёжная компоновка (issue #15, Windows)** — секция переведена
  с хрупкой компоновки (один Grid с ручным перечислением `RowDefinition`, из-за которого
  последняя строка хоткея накладывалась на следующий элемент при добавлении новых хоткеев)
  на внешний StackPanel + самодостаточные строки (подпись 170px + поле HotkeyBox, отступ 6px).
  Теперь добавление любых новых хоткеев не может вызвать наложение надписей; все 30 полей
  сохранены (включая «Меню служб» Ctrl+Shift+Alt+S).
- **«Серверы 1С»: убрано ошибочное сообщение про «файловую базу в кластере» (issue #3,
  Windows и Linux)** — сообщение удалено (файловой базы в кластере в природе не существует);
  вариант «Удалить с удалением на сервере СУБД» предлагается только для известных
  клиент-серверных СУБД.

## Изменено

- **«Управление службами»: отступ строк-папок и иконки в меню служб (issue #11, Windows
  и Linux)** — строки-папки (группы служб) получили недостающий нижний отступ — высота теперь
  совпадает с обычной строкой службы (WPF и Avalonia). В меню служб системного трея
  (Windows/WPF) у групп теперь иконка «микс»: папка + маленький цветной кружок статуса
  справа-снизу (зелёный — все запущены, жёлтый — частично, серый — не запущены; на Linux
  нативные меню не поддерживают цветные иконки — ограничение платформы). В меню служб,
  открываемом по глобальному хоткею «Меню служб» (Ctrl+Shift+Alt+S), добавлены иконки:
  статусные кружки служб, папка с кружком статуса у групп, цветные глифы команд
  (Запустить/Остановить/Пауза/Восстановить/Перезапустить), иконка «Настроить» и «Все
  сервисы» (WPF и Avalonia).
- **«Серверы 1С»: список типов СУБД ограничен четырьмя значениями rac (issue #3, Windows
  и Linux)** — при создании и редактировании информационной базы кластера доступны только
  MSSQLServer, PostgreSQL, IBMDB2, OracleDatabase (убраны SQLite, ServerODBC, FILE и подсказка
  про файловую базу). Обновлены локализации ru/en и тесты.

## Примечания

- Изменения затрагивают обе платформы: **Windows** (WPF) и **Linux** (Avalonia).
- Исправление issue #17 относится к WPF-версии (Avalonia-версия уже работала корректно);
  issue #15 — к WPF-версии (Avalonia-версия не содержала дефекта).
- Микс-иконки групп в меню трея реализованы только на Windows (WPF): на Linux нативные меню
  не поддерживают цветные иконки (ограничение платформы).
- Issues #17, #15, #11, #3 остаются открытыми до подтверждения пользователем.

Подробности — в [CHANGELOG.md](CHANGELOG.md).
