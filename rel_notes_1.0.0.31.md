# Workspace 1C 1.0.0.31

Дата выпуска: **2026-10-21**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Добавлено

- **Экспорт и импорт списка баз в произвольный файл *.v8i (issue #29, Windows и Linux)** —
  в настройках (вкладка «Базы» → «Список баз») добавлены кнопки «Экспорт в файл *.v8i…»
  и «Импорт из файла *.v8i…»: список баз и групп приложения можно сохранить в любой
  файл ibases.v8i (например, для подготовки общего списка информационных баз в отдельном
  профиле) и загрузить из любого файла, не затрагивая основной список пользователя.
  Экспорт в существующий файл — аддитивный (чужие записи не удаляются), в новый —
  полный; импорт использует тот же механизм, что и разовый импорт из ibases.v8i.
- **Добавка к заголовку окна: произвольное дополнение с переменными (issue #28,
  Windows и Linux)** — новый раздел «Заголовок окна» в настройках «Отображение»:
  галочка «Дополнить заголовок программы», поле «Шаблон дополнения» с живым превью
  результата и кликабельные подсказки переменных. Поддерживаются `%computer_name%`,
  `%user_name%`, `%user_domain%`, `%computer_ip%`, `%display_server%` (x11/wayland на
  Linux, «windows» на Windows). Заголовок обновляется при запуске приложения и при
  изменении настроек.

## Исправлено

- **«Цветовое оформление»: образцы-прямоугольники и HEX-текст редактора (issue #26,
  Windows и Linux)** — цвет текста HEX-значений в редакторе цветов теперь контрастен
  ФАКТИЧЕСКОМУ фону строки (карточке активной темы приложения), а не фону редактируемой
  палитры: при редактировании светлой палитры в тёмной теме текст больше не становится
  тёмным и не сливается с формой (и наоборот). Сохранённые правки акцентов встроенных
  «Светлая»/«Тёмная» по-прежнему перекрывают дефолтные #FDBF00/#E0A800 при повторном
  входе (закреплено регрессионным тестом).
- **«Импорт из кластера 1С»: после успешного подключения ошибка не остаётся, прогресс
  завершается, кнопка «Импортировать» доступна (issue #25, Windows и Linux)** — перебор
  форматов передачи идентификатора кластера (`--cluster=<uuid>` / `--cluster <uuid>` /
  позиционный `<uuid>`) распространён на команду «cluster info» (как в «job list»/
  «infobase summary list»), поэтому загрузка баз кластера на rac 8.5.x больше не падает
  после успешного подключения; при ЕДИНСТВЕННОМ кластере он выбирается автоматически
  (при нескольких — пользователь выбирает сам); неожиданные исключения больше не
  оставляют «крутящийся» индикатор прогресса (флаг занятости снимается в finally,
  причина — в журнале).
- **«Вкладки списка баз»: устранено накопление памяти при многократном переключении
  Все/Избранное/Недавние (issue #21, Windows и Linux)** — `ReplaceItemWise` больше не
  уходит в полный Reset при частичном пересечении составов (переход «Все»(600) →
  «Недавние»(10) раньше пересоздавал контейнеры всех строк): Reset выполняется только
  при нулевом пересечении, иначе контейнеры оставшихся строк переиспользуются
  (виртуализация Recycling). Диагностика `CM_TREESWITCH` дополнена замером кучи
  (`heapMb`) — рост памяти с каждым переключением виден сразу в журнале.
