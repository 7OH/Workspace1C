# Workspace 1C 1.0.0.0

Первый выпуск под новым названием. **Workspace 1C** — это продолжение программы
«Управление конфигурациями 1С» (последняя версия под прежним названием — 0.3.12.70):
все возможности сохранены, нумерация версий начинается заново с 1.0.0.0.

📣 Новости, анонсы выпусков и обсуждение — в Telegram-канале: https://t.me/Workspace1C

## Изменено

- Новое название программы — **Workspace 1C** (заголовок окна, «О программе», уведомления,
  HTML-отчёт, ярлык и пакет для Linux).
- Исполняемые файлы: `Workspace1C.exe` (Windows) и `Workspace1C-linux-x64` (Linux).
- Новый репозиторий и проверка обновлений: https://github.com/sivatorov/Workspace1C —
  автообновление теперь получает выпуски отсюда.
- Каталог данных: `%APPDATA%\Workspace1C` (Windows), `~/.config/Workspace1C` (Linux).

## Перенос настроек

- При первом запуске данные из прежнего каталога `ConfigurationManagement` (список баз,
  группы, настройки, профили, схемы, задания) **копируются** в новый каталог автоматически.
  Старый каталог не удаляется.
- Портативный режим: если рядом с exe есть только прежний каталог
  `ConfigurationManagement-Data`, программа продолжает работать с ним.
- Автозапуск с Windows, если был включён в прежней версии, нужно включить заново
  в настройках Workspace 1C (у новой программы своя запись автозапуска).

## Загрузка

| Платформа | Файл |
|---|---|
| Windows x64 | `Workspace1C.exe` |
| Linux x64 | `Workspace1C-linux-x64` (`chmod +x Workspace1C-linux-x64`) |
