# Workspace 1C 1.0.0.20

Дата выпуска: **2026-10-19**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **«Управление службами»: меню служб по Ctrl+ПКМ в трее теперь закрывается по клику вне
  меню и по ESC (issue #11, Windows)** — в v1.0.0.18 меню служб показывалось вручную через
  `Show()`: из-за этого в трей-приложении без активного окна терялся нативный контур
  закрытия, меню оставалось открытым после клика в другом месте и не реагировало на ESC
  (обычное меню трея при этом закрывалось штатно). Исправление: меню служб строится из
  прогретого кэша и **подменяет штатный `ContextMenuStrip` трея ещё на MouseDown** — до
  старта системного показа, поэтому `NotifyIcon` открывает его тем же механизмом, что и
  обычное меню (с корректным владельцем-окном). Клик по другому окну и ESC закрывают меню
  служб так же, как обычное меню. Состояние (флаг `_ctrlRightClickPending`) сбрасывается
  при закрытии меню (Closed), повторный Ctrl+ПКМ при открытом меню игнорируется (двойных
  меню нет), правый клик БЕЗ Ctrl продолжает открывать штатное меню. Добавлена чистая
  логика решений `TrayServicesMenuDecider` и юнит-тесты к ней.

## Примечания

- Мгновенный Ctrl+ПКМ в трее (v1.0.0.18) сохранён: меню собирается из прогретого кэша
  статусов служб без синхронных опросов.
- Issue #11 остаётся открытым до подтверждения пользователем (автозакрытие issues по
  сообщению коммита отключено).
