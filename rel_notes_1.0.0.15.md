# Workspace 1C 1.0.0.15

Дата выпуска: **2026-10-19**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Добавлено

- **Меню списка избранного подчиняется скинингу (issue #16, Windows и Linux)** — меню
  закладок (Ctrl+B, `ShowBookmarksMenu`) приведено к виду контекстных меню основного окна:
  применяются стили скина `ModernContextMenu`/`ModernMenuItem` (WPF и Avalonia). В тёмной
  теме пункты меню тёмные со светлым текстом, в светлой — светлые, как у контекстного меню
  основного окна.
- **«Управление службами»: настраиваемый хоткей «Меню служб» (issue #11, Windows и Linux)** —
  по умолчанию `Ctrl+Shift+Alt+S`; по нажатию у курсора показывается контекстное меню служб
  (как подменю закладок по Ctrl+B): команды Запустить/Остановить/Пауза/Восстановить/
  Перезапустить для всех служб и групп. Настраивается в «Настройки → Клавиши».
- **«Управление службами»: запоминание состояния сворачивания групп (issue #11, Windows
  и Linux)** — новые поля настроек `CollapsedServiceGroups` и `ServiceGroupsStateInitialized`;
  группы служб свёрнуты по умолчанию, состояние сворачивания сохраняется между сеансами
  (как у списка баз).

## Изменено

- **«Управление службами»: не разворачиваются все папки при выделении строки службы
  (issue #11, Windows и Linux)** — выделение строки больше не раскрывает принудительно
  все группы; группы раскрываются только явным кликом по «+»/стрелке (как в списке баз
  основного окна).
- **«Управление службами»: контекстное меню строки и подменю «Все сервисы» приведены к виду
  контекстного меню основного окна (issue #11, Windows и Linux)** — стили скина, цветные
  иконки команд, подписи и доступность по состоянию службы.
- **«Управление службами»: иконки «Свернуть все»/«Развернуть все» совпадают с такими же
  в главном окне (issue #11, Windows и Linux)** — PackIcon ExpandAll/CollapseAll,
  IconExpandAllBox/IconCollapseAllBox.
- **«Управление службами»: кнопки «Переместить выше/ниже» меняют порядок служб ВНУТРИ
  группы (issue #11, Windows и Linux)** — при выделенной службе внутри группы порядок
  меняется в пределах группы и сохраняется в services.json.

## Исправлено

- **Настройки → «Клавиши»: двойная надпись в последней строке хоткея (issue #15, Windows)** —
  добавлена недостающая `RowDefinition` для `Grid.Row=28` в WPF; последняя строка хоткея
  содержит ровно одну надпись.

## Примечания

- Изменения затрагивают обе платформы: **Windows** (WPF) и **Linux** (Avalonia).
- Исправление issue #15 относится к WPF-версии (Avalonia-версия не содержала дефекта).
- Issues #16, #15, #11 остаются открытыми до подтверждения пользователем.

Подробности — в [CHANGELOG.md](CHANGELOG.md).
