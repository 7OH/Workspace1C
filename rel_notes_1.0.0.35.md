# Workspace 1C 1.0.0.35

Дата выпуска: **2026-10-21**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **«Заголовок окна»: дополнение из шаблона теперь видно сразу после запуска,
  без захода в настройки (issue #34, Windows и Linux)** — заголовок (и видимая
  шапка на Windows) при старте собирается общим методом окна с актуальными
  настройками профиля — тем же путём, что и после «ОК» настроек. На Windows
  раньше по завершении запуска обновлялся только системный заголовок, а шапка
  с дополнением появлялась лишь после открытия/закрытия настроек (пересборка
  заголовка при старте не выполнялась); Avalonia переведена на тот же единый
  источник, чтобы исключить рассинхрон двух мест сборки заголовка.
- **«Импорт из кластера 1С»: выбор другого сервера очищает состояние прошлого
  подключения и снова делает доступной кнопку «Подключиться»; прогресс и кнопки
  не «застревают» (issue #25, Windows и Linux)** — при смене сервера в списке
  очищаются кластеры, чеклист баз, выбор кластера, результат импорта и текст
  ошибки/статуса, а «Подключиться» становится доступной сразу (раньше кнопка
  оставалась в состоянии после предыдущей операции, «даже после выбора другого
  сервера»); уведомления о занятости теперь доставляются окну на UI-поток —
  индикатор прогресса всегда завершается, а «Импортировать» включается при
  отмеченных новых базах после успешной загрузки.

## Примечания

- Issues #34 и #25 остаются открытыми до подтверждения пользователями
  (автозакрытие issues по сообщению коммита отключено); после релиза
  в каждый issue добавляется комментарий «что исправлено и в какой версии».
- По issue #25 это третья итерация исправлений (ранее 1.0.0.30/1.0.0.31/1.0.0.33
  закрывали ошибку «cluster info» и передачу кластера из «Серверы 1С»);
  в 1.0.0.35 устранено оставшееся поведение кнопок/прогресса при смене сервера.
