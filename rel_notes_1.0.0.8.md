# Workspace 1C 1.0.0.8

Дата выпуска: **2026-10-16**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Изменено

- **Удалена вкладка «Регламентные задания» в окне «Серверы 1С»** (issue #3, Windows и Linux):
  команды rac «job» не существует в списке режимов rac 8.5.4 и 8.3.27, а ссылка на ИТС
  недоступна — вкладка и `rac job list` были «галюцинацией». Вкладка, фильтр по базе,
  кнопки «Приостановить/Возобновить/Детали» и загрузка заданий удалены полностью;
  статус-строка больше не считает задания.
- **Выбор базы фильтрует сеансы/соединения/блокировки на клиенте** (issue #3, Windows
  и Linux): раньше при выделении базы запускалась полная перезагрузка кластера
  (7 параллельных rac-процессов), а параметр `--infobase` для session/connection/lock
  list на платформе пользователя не работает — окно зависало с «Загрузка данных
  кластера» до CommandTimeout, а вкладки оставались пустыми. Теперь данные кластера
  всегда запрашиваются целиком, а выбор базы мгновенно фильтрует уже загруженный
  снимок на клиенте — без rac-вызовов и без флага занятости. Сброс «Все базы»
  показывает все данные. Активный фильтр виден: строка «Фильтр по базе: <Имя>»
  с кнопкой «Сбросить» в правой панели.
- **Видимая индикация сортировки колонок** (issue #3, Windows и Linux): стрелка ▲/▼
  у активной колонки всегда видна — акцентный цвет, заголовок с усечением, стрелка
  не переносится и не «съедается» длинным заголовком; на WPF добавлен явный
  обработчик сортировки, сбрасывающий стрелки у остальных колонок.

Подробности — в [CHANGELOG.md](CHANGELOG.md).
