# Workspace 1C 1.0.0.30

Дата выпуска: **2026-10-21**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **«Импорт из кластера 1С» на платформе 8.5.1 (Windows Server 2025): подключение
  к кластеру и загрузка списка баз (issue #25, Windows и Linux)** — rac 8.5.x
  отклоняет аргумент `--cluster=<uuid>` (код -1) не только в «job list» (как
  8.5.4.1878, issue #324), но и в «infobase summary list» — команде загрузки
  чеклиста баз окна импорта. Теперь:
  - перебор форматов передачи идентификатора кластера в list-командах rac
    (`--cluster=<uuid>` / `--cluster <uuid>` / позиционный `<uuid>`) вынесен
    в общий helper `ClusterArgs` и применён к «infobase summary list» наравне
    с «job list»; первый успешный формат запоминается в персистентном кэше
    (ключ дополнен именем команды — кэш «job list» и «infobase summary list»
    не конфликтует), повторные подключения не тратят rac-запуски на заведомо
    падающие попытки; для rac 8.3/8.4 формат по умолчанию (`--cluster=<uuid>`)
    успешен с первой попытки — поведение не изменилось;
  - распознавание новых имён ключей/стартeров блочного формата 8.5.x:
    «cluster-id» (вместо «cluster»), «infobase-summary-id» (вместо
    «infobase»/«infobase-id»), имена «displayName»/«display-name» (вместо
    «name»), поля «dbServer»/«dbName»/«securityLevel» (вместо дефисных);
  - ошибки парсинга rac (`RacOutputParseException`) теперь содержат префикс
    вывода rac (первые ~200 символов, пароль маскируется) — при следующем
    новом формате причина видна сразу в сообщении окна, без чтения журнала.
- **«Цветовое оформление»: сохранённые акцентные цвета корректно отображаются
  при повторном входе; HEX-значения контрастны в тёмной и светлой темах
  (issue #26, Windows и Linux)** — редактор цветов и палитра больше не сбрасывают
  правки «Акцентный цвет»/«Акцент (наведение)» встроенных тем на дефолтные
  #FDBF00/#E0A800: правки читаются из сохранённой активной схемы/слота, а не из
  «чистого» каталога встроенных схем (WPF и Avalonia); предпросмотр полноценной
  темы не затирает активную схему до подтверждения; цвет текста HEX-значений
  выбирается по контрасту с фоном палитры (WCAG) — в тёмной теме он больше
  не чёрный и не сливается с формой.
- **«Серверы 1С»: импорт баз из кластера через справочник серверов (issue #27,
  Windows и Linux)** — окно «Импорт из кластера 1С» вместо четырёх полей
  (адрес/порт/логин/пароль) использует список серверов из справочника
  «Серверы 1С»: параметры берутся из выбранной записи, пароль — только в памяти
  окна (на диск не пишется). В окне «Серверы 1С» колонка «Базы» расширена
  до 260 px (кнопки стали шире после 1.0.0.25 и последняя не влезала), под
  списком баз добавлена кнопка «Импорт» (по аналогии с «СЛУЖБЫ» под списком
  серверов) — открывает «Импорт из кластера 1С» с сервером, текущим на момент
  нажатия (`SelectedServer`, иначе `ConnectedServer`, иначе первый), и сразу
  подключается. При пустом справочнике в окне импорта — локализованная подсказка
  и недоступное «Подключиться». Логика «добавить базы/группы, сохранить,
  пересобрать дерево» вынесена в общий `ApplyClusterImportResult` — единый для
  WPF и Avalonia, без дублирования; команда меню «Утилиты → Операции → Импорт
  из кластера 1С…» открывает окно без параметров (без автоподключения).
