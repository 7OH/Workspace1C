# Workspace 1C 1.0.0.6

Дата выпуска: **2026-10-16**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **Тёмная тема сохраняется после перезапуска и автообновления приложения** (Windows и Linux):
  раньше выбор тёмного варианта темы кнопкой «Светлая/Тёмная» сохранялся только в поле
  `AppSettings.Theme="Dark"`, а при старте приложение применяло лишь полноценную тему
  (`FullTheme`, по умолчанию «light») — поэтому после перезапуска (в том числе после
  автоматического обновления программы) тема становилась светлой. Теперь сохранённый вариант
  `Theme="Dark"` при старте применяется к выбранной полноценной теме через новый чистый метод
  `ThemeFeatureMap.ResolveDarkVariant` — во всех точках запуска: WPF и Avalonia, главное окно и
  окно входа в систему. Обычные миграции (`NormalizeThemeSelection`) не менялись; корректность
  покрыта новыми тестами `AppSettingsThemeMigrationTests`.

Подробности — в [CHANGELOG.md](CHANGELOG.md).
