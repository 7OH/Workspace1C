# Workspace 1C 1.0.0.11

Дата выпуска: **2026-10-17**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Серверы 1С (issue #3)

- **Полный диалог свойств базы**: «Изменить» открывает окно «Свойства информационной базы»
  с полями как в консоли кластера — СУБД, выдача лицензий, блокировка начала сеансов
  (начало/окончание/сообщение/код разрешения/параметр), блокировка регламентных заданий,
  внешнее управление сеансами, профили безопасности.
- **Логин и пароль администратора ИБ** берутся из списка баз программы (та же база на том же
  сервере); если их нет — вводятся в диалоге, «Обновить» перечитывает свойства.
- Вертикальные линии в таблицах и заголовках, ширина колонок снова меняется, по умолчанию
  колонки шире — стрелка сортировки не обрезает название.
- Окно больше не перекрывает главное (Windows).
- Список баз — на одном уровне с вкладками, всегда по алфавиту; кнопки «А→Я / Я→А»
  (порядок: Добавить, Правка | А→Я, Я→А | Удалить).
- Изменение и создание базы: команды rac собираются по её ключам (`--descr`, `on|off` и др.).

## Управление службами (issue #11)

- **«Выдать права»** (Windows): текущий пользователь получает право запускать и останавливать
  службы списка без запуска программы от администратора — одним запросом повышения прав на все
  службы. При добавлении служб через «Настроить» это предлагается сразу.
- Окно модальное, сообщения модальны к нему; кнопки «Переместить выше / ниже»; цветные иконки
  с подписями; в «Настроить» — ОК/Отмена над списком, службы по алфавиту.

## Обновления конфигураций

- **Учётная запись ИТС (issue #13)**: для базы, сопоставленной с типовой конфигурацией по
  имени (без явной связи), F9 и задание проверки обновлений используют учётную запись этой
  конфигурации, а не «Основную». В журнале CM_UPDATES видно, какая запись выбрана.
- **«Типовые конфигурации» (issue #12)**: сортировка по любой колонке со стрелкой ▲/▼,
  по умолчанию — по наименованию.
- **Основная редакция (issue #14)**: флаг «Основная» и кнопка «Сделать основной»; блок
  `DefaultEdition` больше не дублируется в `custom_config_types.json`.

## Уведомления (issue #10)

- При успешном автообновлении приходит одно сообщение «Приложение обновлено до версии X» —
  без отдельного «Задание выполнено».
