# Workspace 1C 1.0.0.5

Дата выпуска: **2026-10-16**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **«Версия актуальна» — больше не ошибка обновления** (issue #8, Windows и Linux): задание по
  расписанию «Проверка обновлений программы» (тип `UpdateApp`), обнаружившее, что установлена
  актуальная версия приложения, помечалось как завершённое ошибкой — в Telegram и системные
  уведомления уходило «❌ Задание завершилось ошибкой». Теперь «версия актуальна» — успешное
  завершение: в результат и `LastRunMessage` записывается «Установлена актуальная версия»,
  а уведомление о завершении не отправляется (защита от спама при повторе каждые N минут).
  Настоящие ошибки (сбой проверки GitHub, отсутствие ссылки на загрузку, сбой скачивания)
  по-прежнему фиксируются как ошибки.
- **Старт автообновления заданий без перезапуска приложения** (issue #7, Windows и Linux):
  задание, добавленное или изменённое в окне «Задания по расписанию» во время работы
  приложения (например, включён повтор каждые 5 минут), не выполнялось, пока приложение
  не перезапустят. Теперь при сохранении/удалении задания (в т.ч. переключении активности)
  планировщик сразу пересчитывает расписание (`SchedulerService.Refresh()`): новые задания
  попадают в него немедленно, изменённые получают актуальный ближайший момент запуска
  с учётом повтора.
- **Произвольные поля базы: сохранение и подстановка** (issue #6, Windows и Linux): исправлен
  баг — значения таблицы «Произвольные поля» на вкладке «Идентификатор» не сохранялись в базу
  и не подставлялись в сценарии токеном `%Additional_N%`. Теперь поля переносятся из окна
  свойств базы в модель, сохраняются в `infobases.json` и корректно подставляются при
  формировании строки запуска сценария и пользовательских действий (пустая строка даёт
  пустое значение).

## Изменено

- **Таблица «Произвольные поля»** (issue #6, Windows и Linux): при открытии дополняется
  пустыми строками до минимума (5 строк) — сразу видно, куда вводить значения; при сохранении
  хвостовые пустые строки обрезаются. Заголовки таблицы раскрашены контрастно: в WPF — стиль
  шапки `DataGrid`, в Avalonia — строка-шапка «№ | Значение поля» над списком с акцентным фоном.
