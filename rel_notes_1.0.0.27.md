# Workspace 1C 1.0.0.27

Дата выпуска: **2026-10-20**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **«Вкладки списка баз»: переключение «Все / Избранное / Недавние» ускорено (issue #21,
  Windows и Linux)** — устранены повторные пересчёты колонок и лишние проходы раскладки;
  введён кэш расчёта ширины колонок; обновление min-width колонок при прокрутке выполняется
  с дебаунсом; группированное дерево режима «Все» кэшируется и переиспользуется; при чистой
  смене вкладки выделение/фокус не восстанавливаются (цель из прежнего режима в новом, как
  правило, недостижима); признаны «Последние» и «Часто используемые».
- **Окно проверки обновлений: заголовок теперь просто «Проверка обновлений» (issue #23,
  Windows и Linux)** — убран лишний суффикс из заголовка окна.

Релиз: [https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.0.27](https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.0.27).
