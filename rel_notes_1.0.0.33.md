# Workspace 1C 1.0.0.33

Дата выпуска: **2026-10-21**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **«Цветовое оформление»: повторный вход в настройки показывает сохранённые
  акцентные цвета, а не дефолтные жёлтые (issue #26, Windows и Linux)** — редактор
  цветов при открытии сразу строит строки по палитре активной темы (с сохранёнными
  правками «Акцентный цвет»/«Акцент (наведение)»), поэтому прямоугольники-образцы
  и диалог выбора цвета больше не показывают дефолтные #FDBF00/#E0A800 после
  установки своих цветов и повторного входа; контрастная кисть HEX-текста
  (1.0.0.30/1.0.0.31) сохранена.
- **«Импорт из кластера 1С»: ошибка после успешного подключения не блокирует
  загрузку баз; из окна «Серверы 1С» подставляется выбранный кластер; прогресс
  всегда завершается; кнопка «Импортировать» доступна при выбранных базах
  (issue #25, Windows и Linux)** — сбой команды «cluster info» (используется только
  для подписи хоста в строке подключения) больше не оставляет ошибку в окне импорта;
  при открытии из «Серверы 1С» передаётся и кластер, выбранный в мониторе (иначе —
  автовыбор единственного; при нескольких — подсказка «выберите кластер», прогресс
  остановлен); кнопка «Импортировать» включается только при отмеченных новых базах.
- **«Вкладки списка баз»: диагностика накопления памяти на Windows расширена
  (issue #21)** — лог `CM_TREESWITCH` дополнен числом событий коллекций дерева
  (Add/Remove/Reset за смену вкладки), замером кучи после принудительного GC и
  счётчиками поколений сборщика — для различения отложенного освобождения
  контейнеров строк от реальной утечки подписок при переключении
  Все/Избранное/Недавние.

Релиз: https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.0.33

## Примечания

- Issues #21, #25 и #26 остаются открытыми до подтверждения пользователями по итогам
  релиза (автозакрытие issues по сообщению коммита отключено); в каждый issue после
  релиза добавлен комментарий «что исправлено и в какой версии».
- По issue #21 запрошен повторный лог `CM_TREESWITCH` после 30 переключений на
  Windows — по замерам (heapAfterGcMb/gc0/gc1/gc2/collAdd/collRemove) будет принято
  решение о дальнейшей оптимизации.
