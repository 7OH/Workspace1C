# Workspace 1C 1.0.0.52

Дата выпуска: **2026-10-22**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **Устранён рост памяти и тормоза при переключении вкладок «Все / Избранное / Недавние»
  на Windows (issue #21)**:
  - панели дерева переведены на `VirtualizationMode.Standard` — `ItemContainerGenerator`
    не рециклирует контейнеры строк, поэтому пул и рост `heapAfterGcMb`
    (в 1.0.0.46–1.0.0.50: up to ~4 МБ/смену, 29 → 347 МБ за ~65 переключений) не
    накапливаются;
  - динамическое переключение режима после Measure панели (источник
    `InvalidOperationException` в 1.0.0.50, лог `CM_TREESWITCH_FLUSH`) удалено как
    неработоспособное;
  - диагностика `CM_TREESWITCH` сохранена: `flushPanels`/`flushMs` теперь всегда 0
    (пул не используется), главный показатель фикса — стабильный `heapAfterGcMb`.

## Изменено

- **Единые названия «Импорт/Экспорт» в настройках (issue #29)**: кнопки «Загрузить из файла» /
  «Выгрузить в файл» (вкладка синхронизации ibases.v8i) переименованы в **«Импорт из файла…»** /
  **«Экспорт в файл…»**, операция «Загрузка списка баз из файла» (JSON) — в
  «Импорт списка баз из файла»; тексты справки и тултипов приведены к единой терминологии
  (как в меню «Утилиты»).
- **Кнопка «Мигрировать» (issue #41)**: теперь доступна при ЛЮБОЙ отмеченной базе — проверка
  готовности к импорту (дубликаты/причины пропуска) больше не блокирует перенос. В диалоге
  миграции при выборе кластера назначения выполняется проверка «база уже есть в приёмнике»:
  при конфликте окно предупреждает и запрашивает подтверждение (повторный перенос после
  сбоя остаётся доступен).
- **Детали в оповещении об обновлении (issue #44)**: в уведомление о доступной новой версии
  (почта/Telegram) добавлено **«Что нового:»** — описание изменений из выпуска
  (до 2000 символов) и ссылка на страницу релиза, как список изменений в главном окне.
- **Радиокнопки «Текущая сессия» (issue #45)**: подписи приведены к полным названиям как в
  StartManager — «Авто (по настройкам базы)», «Обычное приложение (обычные формы,
  /RunModeOrdinaryApplication)», «Толстый клиент (управляемые формы, /RunModeManagedApplication)»,
  «Тонкий клиент (управляемые формы)»; всплывающая подсказка «Полный клиент…» у «Толстого»
  убрана, текст подсказки «?» структурирован с подпунктами (по предложению 7OH).
- **Дополнен список типовых конфигураций (PR #43, 7OH)**: добавлены **Бухгалтерия предприятия
  КОРП**, **Документооборот ПРОФ** и **КОРП**, **Зарплата и управление персоналом КОРП**,
  **рабочее место кассира**, **Управление нашей фирмой**, **Управление производственным
  предприятием**. Редакции и каталоги релизов (`UrlOverride`) приведены к актуальным:
  хранятся конечной частью адреса `releases.1c.ru/project/<код>` — полная ссылка собирается
  автоматически. Юнит-тесты встроенного набора обновлены.

При переключении вкладок на Windows после перехода на `VirtualizationMode.Standard` ожидается
стабильный `heapAfterGcMb` в логе `CM_TREESWITCH` (флаг можно включить в trace.json). Если рост
сохранится — пришлите лог после ~30 переключений вкладок.
