# Workspace 1C

![Windows/WPF](https://img.shields.io/badge/Windows-WPF-4B8BBE) ![Linux/Avalonia](https://img.shields.io/badge/Linux-Avalonia%2011-8B5CF6) ![Лицензия](https://img.shields.io/badge/Лицензия-MIT-success) [![Telegram](https://img.shields.io/badge/Telegram-@Workspace1C-26A5E4?logo=telegram&logoColor=white)](https://t.me/Workspace1C)

**Workspace 1C** - менеджер информационных баз 1С:Предприятие 8.3. Список баз, копии, обновления и обслуживание в одном приложении для Windows и Linux.

## С чего начать

1. Скачайте готовый файл со страницы Releases. .NET ставить не нужно.
2. Перетащите каталог базы в окно или импортируйте список из `ibases.v8i`.
3. Настройте копии. Создайте сценарий резервирования, потом задание по расписанию.

![Главное окно](docs/img/main-window.png)

_Главное окно со списком баз, группами и быстрым запуском._

## Командная строка

Команды работают без графического окна, их можно звать из ярлыка, скрипта или планировщика ОС.

| Команда | Что делает |
| --- | --- |
| `--run "Имя базы"` | Запускает базу без открытия окна программы |
| `--designer` | Открывает базу в конфигураторе вместо 1С:Предприятия |
| `--list` | Печатает список баз вместе с идентификаторами |
| `--json` | Выдаёт результат в машиночитаемом виде |
| `--profile <id>` | Работает с выбранным профилем пользователя |

| Код возврата | Значение |
| --- | --- |
| 0 | Успех |
| 1 | Ошибка |
| 2 | База не найдена |
| 3 | Частичный успех |

## Скачать и сборка

Готовые сборки лежат одним файлом, .NET ставить не нужно. Нужная система определяется сама, WPF на Windows и Avalonia на Linux.

| Платформа | Файл | Запуск |
| --- | --- | --- |
| Windows 10/11 x64 | `Workspace1C.exe` | двойной щелчок |
| Linux x64 | `Workspace1C-linux-x64` | `chmod +x` и запуск |

Программа сама проверяет новую версию и предлагает обновиться. Сборка из исходников:

```bash
git clone https://github.com/sivatorov/Workspace1C.git
cd Workspace1C
dotnet build "Workspace1C/Workspace1C.csproj"
dotnet run --project "Workspace1C/Workspace1C.csproj"
```

Скрипты сборки и упаковки в один файл лежат в репозитории (`build.sh`, `build.ps1`, `package/linux/`).

## Требования и ограничения

- Windows 10/11. Готовая сборка работает без установки .NET.
- Linux x64 на Ubuntu LTS, Debian, ALT или Astra. Нужны GTK3, glib2 и `xdg-utils`, для трея в GNOME может понадобиться AppIndicator.
- Для сборки из исходников нужны .NET 10 SDK и установленная платформа 1С:Предприятие 8.3.

> На Linux нет COM-коннектора 1С, поэтому клиент-серверные базы при проверке доступности всегда помечаются недоступными. Интеграция с проводником и часть управления службами работают только на Windows.
