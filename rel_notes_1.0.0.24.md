# Workspace 1C 1.0.0.24

Дата выпуска: **2026-10-20**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **«Блокировка базы»: диалог стал полностью модальным, закрывается по ESC, кнопки всегда видны
  (issue #20, Windows и Linux)** — окно блокировки сеансов открывается с владельцем главного окна
  (WPF), поля ввода помещены в прокручиваемую область, а кнопки «Разрешить работу»/«Заблокировать»
  зафиксированы снизу и не обрезаются (высота окна увеличена, кнопки шире); ESC закрывает диалог
  без действий (WPF — PreviewKeyDown; Avalonia — уже закрывал ModalWindowBase).
- **«Блокировка базы»: блокировка файловой ИБ через файл 1cv8.cdn (issue #20, Windows и Linux)** —
  для файловых баз блокировка сеансов выполняется созданием файла `1cv8.cdn` в каталоге базы
  (формат `{1,ГГГГММДДЧЧММСС,ГГГГММДДЧЧММСС,"причина","код разрешения"}`, кавычки удваиваются),
  снятие — удалением файла; в диалог добавлено необязательное поле «Код разрешения». Для
  клиент-серверных баз сохранён прежний механизм `/LockIB` конфигуратора. Добавлены юнит-тесты
  `SessionLockOptionsTests` и `FileBaseSessionLockTests`.
- **«Серверы 1С»: вкладки подчиняются тёмной теме (issue #3, Windows и Linux)** — в тёмном режиме
  вкладки окна были белыми и надписи не читались; добавлены темы вкладок на DynamicResource
  (Avalonia — `ServerMonitorTabControl`/`ServerMonitorTabItem` в Controls.axaml, WPF — собственный
  шаблон TabItem с фоном/текстом/границей из темы).
- **«Серверы 1С»: кнопки управления серверами — иконками без надписей + «Вверх»/«Вниз» (issue #3,
  Windows и Linux)** — кнопки «Добавить/Изменить/Удалить» справочника серверов стали иконками
  (как у списка баз), добавлены кнопки «Вверх»/«Вниз» для изменения порядка записей
  (порядок: Добавить, Изменить | Вверх, Вниз | Удалить); кнопки-иконки управления серверами и
  базами стали шире (раза в полтора). Добавлены юнит-тесты перемещения в `ServerMonitorViewModelTests`.

## Примечания

- Issues #3 и #20 остаются открытыми до подтверждения пользователем (автозакрытие issues по
  сообщению коммита отключено).
