# Workspace 1C 1.0.0.23

Дата выпуска: **2026-10-20**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **«Создание базы на сервере»: из списка СУБД убран SQLite (issue #19, Windows и Linux)** —
  при создании пустой базы на сервере и при клонировании клиент-серверной базы в поле СУБД
  присутствовала лишняя строка «SQLite», которую 1С не поддерживает (замечание 7OH от 19.10).
  Исправление: `SQLite` удалён из списков выбора СУБД в `CreateInfobaseWindow` и
  `CloneServerInfobaseWindow` (WPF — XAML, Avalonia — массив `DbmsValues`); остались ровно
  значения rac «--dbms»: MSSQLServer, PostgreSQL, IBMDB2, OracleDatabase. Константа
  `RacDbms.Sqlite` сохранена для разбора вывода rac и тестов.
- **«Серверы 1С»: поле ЛОКАЛЬ заменено на список выбора локалей (issue #3, Windows и Linux)** —
  при создании/изменении базы в кластере поле ЛОКАЛЬ было текстовым, и пустое значение rac не
  принимал (замечание 7OH от 19.10: «Пустую не принимает… сделать список выбора, в котором
  будет именно выбран по-умолчанию Русский»). Исправление: новый `RacLocales` — список
  двухбуквенных кодов локалей 1С (ru, en, uk, kk, de, fr, es, it, pl, cs, tr, vi, ar, zh, ja)
  с нормализацией полных кодов вида «ru_RU» → «ru»; поле ЛОКАЛЬ в `RacInfobaseCreateWindow`
  (WPF и Avalonia) стало нередактируемым `ComboBox` с выбранным по умолчанию Русским; при
  редактировании базы выбирается текущая локаль из вывода rac. Добавлены юнит-тесты
  `RacLocalesTests`.

  сообщению коммита отключено).
