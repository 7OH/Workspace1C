# Workspace 1C 1.0.0.13

Дата выпуска: **2026-10-18**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Учётная запись ИТС (issue #13)

- **Изоляция сессии и состояния входа по учётной записи**: проверка обновлений конфигураций
  (окно F9, задание «Проверка обновлений конфигурации», загрузка дистрибутива платформы)
  больше не переиспользует сессию/состояние входа другой учётной записи ИТС — сессия
  привязана к учётной записи (конфигурации → из настроек → «Основная»). Раньше, если
  сначала проверить базу с «Основной» учёткой, следующая база с привязанной учёткой
  фактически запрашивала каталог под чужой сессией (в окне показывалась правильная учётка,
  а в дампе страницы — другая). Для одной и той же учётки живая сессия по-прежнему
  переиспользуется.
- Диагностика CM_UPDATES отражает фактическую учётную запись (запись конфигурации, а не
  всегда «Основную»).

## Управление службами (issue #11)

- Исправлен сбой при «Добавить группу» (XamlParseException «Объект Style не может изменять
  свойство Style»): стиль кнопки-иконки в окне группы наследует базовый стиль через
  `BasedOn` вместо запрещённого сеттера `Style`.
- Контекстное меню строки и подменю «Все сервисы» приведены к единому виду контекстного
  меню основного окна (иконки, подписи, доступность по состоянию службы).
- Иконка «Восстановить» отличается от «Запустить» (к треугольнику дорисована палочка).
- На панели у кнопок команд (Запустить/Остановить/Пауза/Восстановить/Перезапустить) убраны
  текстовые подписи (остались в контекстном меню); кнопки стали чуть шире кнопки
  «Добавить группу».
- В трее иконки команд — как на панели (вместо кружков); после «Настроить…» добавлен
  разделитель.

## Серверы 1С (issue #3)

- Диалог «Свойства информационной базы» разбит на 2 вкладки — «Основная» и «Настройки»
  (меньше высота, без прокрутки).
- Удаление базы: диалог с выбором «Просто удалить из кластера» или «Удалить с удалением на
  сервере СУБД» (для файловых баз доступен только первый вариант); команда rac
  `infobase drop --drop-database`.
- «Информация о кластере»: названия параметров переведены на русский (исправлена
  локализация ключей).
- Внизу левой колонки окна «Серверы 1С» добавлена кнопка «СЛУЖБЫ» (на всю ширину, текст по
  центру) — открывает подменю служб, как в трее по Ctrl+клик.
