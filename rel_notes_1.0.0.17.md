# Workspace 1C 1.0.0.17

Дата выпуска: **2026-10-19**. Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **Окно «Очистка истории запусков»: сброс даты последнего запуска (issue #18, Windows
  и Linux)** — кнопка «Очистить историю» теперь полностью очищает историю запусков базы:
  удаляет все записи И сбрасывает `Infobase.LastLaunchDate`. Раньше обнулялся только список
  записей, из-за чего база оставалась в разделе «Недавние» (он фильтрует базы по
  `LastLaunchDate.HasValue`), хотя история была очищена. В модель `Infobase` добавлен чистый
  метод `ClearLaunchHistory()` (очищает записи, сбрасывает дату, поднимает `PropertyChanged`
  для `LaunchHistory`, `LaunchHistoryDisplay`, `LastLaunchDisplay`); WPF- и Avalonia-версии
  окна вызывают именно его (раньше — прямое присваивание пустого списка). После очистки
  повторный запуск базы снова создаёт запись истории и дату последнего запуска. Добавлены
  тесты `InfobaseLaunchHistoryTests`; тест строки `ClearHistoryRowViewModel` покрывает
  обновление счётчика после очистки.

## Примечания

- Изменение затрагивает обе платформы: **Windows** (WPF) и **Linux** (Avalonia).
- Логика очистки вынесена в модель (`Infobase.ClearLaunchHistory()`), окна только вызывают её —
  поведение едино для обеих платформ.
- Issue #18 остаётся открытым до подтверждения пользователем.
